# PracticeProject

Java practice repository for low-level design and problem-solving exercises.

## Summary

- Contains Java practice projects organized by topic.
- Includes multiple low-level design implementations under `src/LLD`.
- Each LLD project has its own README with run instructions, sample test case, design notes, and file summary.

## LLD Projects

- [LLD Project Index](./src/LLD/README.md) - Entry point for all low-level design projects in this repository.
- [BookMyShow](./src/LLD/BookMyShow/README.md) - Movie ticket booking LLD with theatres, shows, seats, bookings, and payment.
- [Logger](./src/LLD/Logger/README.md) - Chain-of-responsibility logger with multiple log levels.
- [ParkingLot](./src/LLD/ParkingLot/README.md) - Parking lot design with spots, vehicles, tickets, and manager flow.
- [TicTacToe](./src/LLD/TicTacToe/README.md) - Console Tic Tac Toe game with board logic and winner detection.

Current LLD coverage includes:

- BookMyShow
- Logger
- ParkingLot
